### 🛠 Базовые команды Git
* `git status` — проверить статус файлов в репозитории.
* `git add .` — добавить все изменения к следующему сохранению.
* `git commit -m "сообщение"` — сохранить изменения с комментарием.
* `git push origin main` — отправить сохраненный код на GitHub.
